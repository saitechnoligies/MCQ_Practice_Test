Privacy Policy

How information is handled when you use the MCQ Practice Test application.

Last Updated: October 17, 2026
Summary: MCQ Practice Test runs entirely inside your web browser. Uploaded question files and quiz answers are processed in local memory and are never transmitted to any custom server or database. We use Google Analytics to gather pseudonymous usage metrics and aggregate site interaction statistics.

1. Purpose of This Website

MCQ Practice Test is a free, lightweight, client-side educational practice tool designed to help learners and students test their knowledge using randomized single-choice and multiple-choice questions. It provides instant automated scoring, error review, and retry capabilities without requiring user registration, accounts, or fees.

2. How Your Quiz Data & Question Files Are Processed

We designed this application to prioritize privacy and simplicity through a client-side architecture:

  • Uploaded JSON Question Banks: When you upload a custom question file via the file selector or drag-and-drop, the file is read directly in your browser using the standard Web FileReader API and parsed using client-side JavaScript. Your file is never uploaded, stored, or sent to any server or external database.
  • Quiz Answers and Selections: When you select options, navigate between questions, and submit your quiz, your choices are stored temporarily in your browser's active JavaScript memory (RAM).
  • Scoring & Evaluation: Grading, score calculation, pass/fail status determination, and result breakdowns are performed entirely within your browser code.
  • No Backend Database: This website does not possess or communicate with any custom backend server, application programming interface (API), or persistent database. Once you close or refresh the browser tab, your active attempt data is cleared from memory.

Security & Confidentiality Notice: Because this is a client-side browser application, loaded question content and answer keys reside in your browser's local execution context. Anyone with access to browser developer tools (F12) can inspect the code and answer keys. Do not upload confidential, sensitive, proprietary, or personal information.

3. Google Analytics 4 (GA4)

This website integrates Google Analytics 4 (Measurement ID: G-14VQH0M6HV), a web analytics service provided by Google LLC (“Google”), to understand visitor trends and improve website usability.

What Google Analytics May Collect:

  • Technical and Device Information: Browser type and version, operating system, device model, screen resolution, language preference, and approximate geographic region (derived by Google from incoming IP addresses prior to discarding the IP).
  • Usage Information: Visited URLs, page interactions, referring sites, and timestamps of activity.
  • Custom Quiz Events (Verified Implementation): Based on the application's actual JavaScript implementation (`script.js`), Google Analytics is notified of test lifecycle events using strictly defined numerical and boolean parameters:
    • quiz_start: Dispatched when a valid quiz attempt begins. Transmits:
      • question_count: Total count of questions in the attempt (integer).
      • is_retry: Boolean flag (true if retrying missed questions, false for initial or full test attempts).
    • quiz_complete: Dispatched once when the user submits and finalizes an attempt. Transmits:
      • total_questions: Total questions evaluated (integer).
      • correct_answers: Count of correct answers (integer).
      • incorrect_answers: Count of incorrect answers (integer).
      • unanswered_questions: Count of unanswered questions (integer).
      • score_percent: Final calculated score percentage (number).
      • is_passed: Boolean status indicating whether the score met the chosen passing threshold (true or false).
    Scope of Quiz Data: The actual text of questions, option choices, user-selected answers, and custom uploaded JSON question banks are processed solely in local browser memory and are never transmitted to Google Analytics or any server.
  • Pseudonymous Identifiers & Cookies: Google Analytics sets first-party cookies (such as _ga and _ga_14VQH0M6HV) containing pseudonymous client identifiers to distinguish user sessions across visits. Because online identifiers and device metadata are processed by Google, analytics data is pseudonymous rather than fully de-identified or untraceable.

For more details on how Google processes analytics data, please consult:

  • Google Privacy Policy
  • Google Analytics Data Privacy and Security
  • Google Analytics Opt-out Browser Add-on (to prevent your data from being used by Google Analytics)
