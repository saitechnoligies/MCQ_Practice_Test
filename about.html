About MCQ Practice Test

A fast, flexible, and distraction-free tool for self-directed study and knowledge assessment.

What is MCQ Practice Test?

MCQ Practice Test is a free, lightweight web application designed for students, educators, and lifelong learners who want a straightforward way to practise multiple-choice questions. It runs completely inside your web browser without requiring accounts, logins, installations, or subscriptions.

Key Features

  • Diverse Question Types: Practice both Single-Choice questions (pick the 1 correct answer) and Multiple-Choice questions (select all that apply) with clear visual badges.
  • Custom JSON Question Upload: Easily test yourself on any subject by uploading your own questions in a simple, standardized JSON format. Just drag and drop your .json file on the home screen.
  • Built-in Starter Question Bank: Get started immediately with 10 pre-loaded questions spanning general science, computer science, programming, and web development.
  • Randomized Question & Option Shuffling: Every attempt automatically shuffles both the question sequence and the option choices using the Fisher-Yates algorithm, preventing memorization by position.
  • Interactive Question Navigator: Seamlessly jump between questions, view your answering progress in real time, and receive a reminder before submitting if any questions remain unanswered.
  • Instant Strict Scoring: Get immediate grading upon submission based on strict evaluation rules (full match required on multiple-select questions; unanswered or incorrect choices receive 0 points).
  • Configurable Passing Threshold: Set your target passing benchmark (e.g., 60%, 75%, 90%) right from the setup screen.
  • Comprehensive Result Review: Inspect every question after submission with filter tabs (All, Incorrect Only, Correct Only) to see what you selected versus the correct answers.
  • Targeted Retry: Focus directly on learning by clicking Retry Missed Questions to repeat only the items you answered incorrectly or skipped, or restart the entire quiz reshuffled.

Completely Free & Client-Side

MCQ Practice Test is 100% free with no hidden fees, paywalls, or third-party ads. The entire application runs directly on your device inside your web browser using HTML5, CSS3, and modern vanilla JavaScript with zero external frameworks or heavy dependencies.

All question parsing and answer evaluations happen locally in your browser's memory, ensuring instant responsiveness and protecting your question data from being stored on remote servers.

Supported JSON Format

To create your own question bank, prepare a .json file structured as an array of question objects: 

[
  {
    "id": 1,
    "question": "What is the capital of France?",
    "type": "single",
    "options": [
      { "id": "A", "text": "Rome" },
      { "id": "B", "text": "Paris" },
      { "id": "C", "text": "Berlin" },
      { "id": "D", "text": "Madrid" }
    ],
    "answer": ["B"]
  },
  {
    "id": 2,
    "question": "Which of the following are programming languages?",
    "type": "multiple",
    "options": [
      { "id": "A", "text": "Python" },
      { "id": "B", "text": "HTML" },
      { "id": "C", "text": "Java" },
      { "id": "D", "text": "CSS" }
    ],
    "answer": ["A", "C"]
  }
]

Note: Your results are evaluated using the answer key provided in your question bank. Please ensure the correct answer option IDs are specified in the answer field for each question.

You can load this format directly from the homepage setup screen.
