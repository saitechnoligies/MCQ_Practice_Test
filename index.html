View Supported JSON Format & Requirements

Your JSON file should contain an array of question objects adhering to this structure:

[
  {
    "id": 1,
    "question": "What is the capital of France?",
    "type": "single",
    "options": [
      { "id": "A", "text": "Rome" },
      { "id": "B", "text": "Paris" },
      { "id": "C", "text": "Berlin" },
      { "id": "D", "text": "Madrid" }
    ],
    "answer": ["B"]
  },
  {
    "id": 2,
    "question": "Which are programming languages?",
    "type": "multiple",
    "options": [
      { "id": "A", "text": "Python" },
      { "id": "B", "text": "HTML" },
      { "id": "C", "text": "Java" },
      { "id": "D", "text": "CSS" }
    ],
    "answer": ["A", "C"]
  }
]
  • type: "single" for one answer, "multiple" for one or more answers.
  • options: list of options with unique id and non-empty text.
  • answer: array containing the option IDs of all correct answers.
